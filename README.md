# Advanced Multivariate Statistics Project
The repository contains all the material related to the Advanced Multivariate Statistics exam project, made in collaboration with Elia Zanini and Alberto Polato. The aim of the project is to develop models to correctly classify individuals according to their health status (diabetic or not) and to find groups of patients with similar characteristics.
In the project both standard and advanced robust techniques have been implemented. 
Some of the applied techniques are:

- Linear and robust linear regression
- Logistic and robust logistic regression
- MCD for outlier detection
- Random forest
- Bootstrap
- K-means and trimmed k-means
- Model-based clustering
